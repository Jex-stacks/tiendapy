# TiendaPy - Proyecto Final ACM

Este es nuestro proyecto final para el curso de Python 0 a 100. Es un sistema de consola diseñado para administrar el inventario y las ventas de la tienda de barrio de Don Aurelio, ubicada en Kennedy.

El programa maneja un CRUD de productos, un carrito de compras con descuentos automaticos del 5% y 10%, control de stock en tiempo real, alertas de reabastecimiento por proveedor y un reporte de cierre de caja diario. Todos los datos persisten en archivos de texto plano (.txt) para no perder la informacion.

## Como ejecutar el proyecto
1. Activar el entorno virtual:
   `.\venv\Scripts\Activate.ps1`
2. Instalar las dependencias:
   `pip install -r requirements.txt`
3. Arrancar la tienda:
   `py src/main.py`
